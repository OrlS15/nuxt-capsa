`useCapsaDb()` is auto-imported in server code and returns the Drizzle instance of the `default` database, the same one on every call. You query it as you would any Drizzle database.

```ts twoslash [server/api/posts.get.ts]
import { defineEventHandler } from 'nuxt/server'
import { posts } from '#capsa/db/default/schema'

export default defineEventHandler(async () => {
  const rows = await useCapsaDb().select().from(posts)
  //    ^?
  return rows
})
```

The rest is plain Drizzle: [select](https://orm.drizzle.team/docs/select), [insert](https://orm.drizzle.team/docs/insert), [update](https://orm.drizzle.team/docs/update), [delete](https://orm.drizzle.team/docs/delete), [transactions](https://orm.drizzle.team/docs/transactions), [batch](https://orm.drizzle.team/docs/batch-api) and [`sql`](https://orm.drizzle.team/docs/sql). To query another database, pass its name: [Multiple databases](/database/multiple-databases).

## Relational queries

`db.query` has an entry for every table, and `with` follows the relations of your [`relations.ts`](/database/drizzle/relations).

```ts twoslash [server/api/feed.get.ts]
import { defineEventHandler } from 'nuxt/server'

export default defineEventHandler(async () => {
  const feed = await useCapsaDb().query.posts.findMany({
    columns: { id: true, title: true },
    with: { author: { columns: { name: true } } },
    limit: 10,
  })
  return feed
  //     ^?
})
```

Filters, ordering and the other options are in Drizzle's [relational queries](https://orm.drizzle.team/docs/rqb).

## Insert, update, delete

```ts twoslash [server/api/users.post.ts]
import { defineEventHandler, readBody } from 'nuxt/server'
import { users } from '#capsa/db/default/schema'

export default defineEventHandler(async (event) => {
  const { name, email } = await readBody<{ name: string, email: string }>(event)
  const [user] = await useCapsaDb().insert(users).values({ name, email }).returning()
  //     ^?
  return user
})
```

A row that misses a required column:

```ts twoslash [server/api/users.post.ts]
// @errors: 2741
import { defineEventHandler } from 'nuxt/server'
import { users } from '#capsa/db/default/schema'

export default defineEventHandler(async () => {
  const ada: typeof users.$inferInsert = { name: 'Ada' }
  await useCapsaDb().insert(users).values(ada)
})
```

## Explicit imports

`useCapsaDb` can also be imported from `#capsa/db`, and each database's own module, `#capsa/db/<name>`, exports `getDb()` for the same instance along with its tables as `schema`. Both modules exist only in server code.

```ts twoslash [server/utils/posts.ts]
import { eq } from 'drizzle-orm'
import { getDb, schema } from '#capsa/db/default'

export function postsBy(authorId: number) {
  return getDb().select().from(schema.posts).where(eq(schema.posts.authorId, authorId))
}
```

## In a page

The Vue app has no `useCapsaDb()`. A page gets its rows from an API route with `useFetch`.

```vue [app/pages/index.vue]
<script setup lang="ts">
const { data: feed } = await useFetch('/api/feed')
</script>

<template>
  <ul>
    <li v-for="post in feed" :key="post.id">
      {{ post.title }} by {{ post.author?.name }}
    </li>
  </ul>
</template>
```

To name a row's type in `shared/` or in a component, import it with `import type`, as shown in [Schema](/database/drizzle/schema#row-types-in-shared).
