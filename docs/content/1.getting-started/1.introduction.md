Capsa is a Nuxt module that wires libraries you install yourself, such as Drizzle for databases, into your app. You turn a feature on in `nuxt.config.ts` and write its files, and Capsa generates the code that connects them to Nuxt.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-capsa'],
  capsa: {
    db: {
      default: { provider: 'drizzle', dialect: 'postgresql', driver: 'pglite', migrations: 'onStart' },
    },
  },
})
```

## Databases

Each key of `capsa.db` is a database, and its tables are Drizzle tables in its own folder, `server/capsa/db/<name>/`.

```ts twoslash [server/capsa/db/default/schema/users.ts]
import { pgTable } from 'drizzle-orm/pg-core'

export const users = pgTable('users', t => ({
  id: t.serial().primaryKey(),
  name: t.text().notNull(),
  email: t.text().notNull().unique(),
  createdAt: t.timestamp().defaultNow().notNull(),
}))
```

Server code queries the database with `useCapsaDb()`, which Nuxt auto-imports.

```ts twoslash [server/api/users.get.ts]
import { defineEventHandler } from 'nuxt/server'

export default defineEventHandler(async () => {
  const users = await useCapsaDb().query.users.findMany()
  //    ^?
  return users
})
```

[Installation](/getting-started/installation) sets up these files in your project, step by step.
