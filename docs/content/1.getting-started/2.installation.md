title: Installation

Capsa needs Nuxt 4. These steps add it to a project and set up a `default` database on PGlite, from `nuxt.config.ts` to a working API route.

::steps
### Add the module

```bash [Terminal]
npx nuxt module add nuxt-capsa
```

Or install the package yourself and add `'nuxt-capsa'` to `modules` in `nuxt.config.ts`.

:::code-group
```bash [pnpm]
pnpm add nuxt-capsa
```

```bash [npm]
npm install nuxt-capsa
```

```bash [yarn]
yarn add nuxt-capsa
```

```bash [bun]
bun add nuxt-capsa
```
:::

### Install Drizzle

Capsa builds the database with the Drizzle packages you install. The `rc` tag installs Drizzle v1, and `drizzle-kit` generates the migrations. Capsa lists the versions it supports in its `peerDependencies`, and warns on every build when the ones installed are outside them.

:::code-group
```bash [pnpm]
pnpm add drizzle-orm@rc @electric-sql/pglite
pnpm add -D drizzle-kit@rc
```

```bash [npm]
npm install drizzle-orm@rc @electric-sql/pglite
npm install -D drizzle-kit@rc
```

```bash [yarn]
yarn add drizzle-orm@rc @electric-sql/pglite
yarn add -D drizzle-kit@rc
```

```bash [bun]
bun add drizzle-orm@rc @electric-sql/pglite
bun add -d drizzle-kit@rc
```
:::

### Declare the database

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-capsa'],
  capsa: {
    db: {
      default: { provider: 'drizzle', dialect: 'postgresql', driver: 'pglite', migrations: 'onStart' },
    },
  },
})
```

PGlite keeps the data in `.data/capsa/db/default`, so there is no connection to set, and `'onStart'` makes the server apply migrations as it starts. Every option is on [Setup](/database/drizzle/setup), and every driver on [Drivers](/database/drizzle/drivers).

### Write a table

```ts twoslash [server/capsa/db/default/schema/users.ts]
import { pgTable } from 'drizzle-orm/pg-core'

export const users = pgTable('users', t => ({
  id: t.serial().primaryKey(),
  name: t.text().notNull(),
  email: t.text().notNull().unique(),
  createdAt: t.timestamp().defaultNow().notNull(),
}))
```

The tables of the `default` database live in `server/capsa/db/default/` ([Schema](/database/drizzle/schema)).

### Generate the migration

```bash [Terminal]
npx nuxt prepare
npx drizzle-kit generate --config .nuxt/capsa/db/default/drizzle.config.ts
```

`nuxt prepare` writes the database's drizzle-kit config, and drizzle-kit writes the migration to `server/capsa/db/default/migrations/` ([Migrations](/database/drizzle/migrations)).

### Query it

```ts twoslash [server/api/users.post.ts]
import { defineEventHandler, readBody } from 'nuxt/server'
import { users } from '#capsa/db/default/schema'

export default defineEventHandler(async (event) => {
  const { name, email } = await readBody<{ name: string, email: string }>(event)
  const [user] = await useCapsaDb().insert(users).values({ name, email }).returning()
  //     ^?
  return user
})
```

`useCapsaDb()` is auto-imported in server code and returns the `default` database ([Queries](/database/drizzle/queries)).

### Check it works

Start the dev server, which applies the migration before it answers requests.

```bash [Terminal]
npx nuxt dev
```

Then call the route from a second terminal. The response is the new row.

```bash [Terminal]
curl -X POST http://localhost:3000/api/users -H 'content-type: application/json' -d '{"name":"Ada","email":"ada@example.com"}'
```

```json [Response]
{
  "id": 1,
  "name": "Ada",
  "email": "ada@example.com",
  "createdAt": "2026-10-05T09:19:27.125Z"
}
```
